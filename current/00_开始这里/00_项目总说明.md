# 《AI商业广告全流程制作 SOP V1.0》｜跨聊天窗口项目交接总说明

**交接日期：** 2026-11-03  
**项目名称：** AI商业广告全流程制作 SOP V1.0  
**当前最高模板版本：** T03-01～T03-06 V1.1.0（T03-08发布）  
**注意：** SOP文档/模板静态验收通过，不等于真实商业广告生产、模型生成、客户验收或投放验证通过。

## 1. 这是什么

这是一个以AI主导、兼容实拍/CG混合制作的商业广告全流程生产系统，覆盖从Brief接收、品牌产品研究、商业策略、创意、脚本与导演、分镜、视觉资产、AI/混合生产、后期、商业审核与交付，到可选的投放复盘。

**冻结架构：** 12个阶段（P0～P11）、99项正式步骤、10个主Gate（G0～G9，其中G7拆为G7a、G7b两个子审核）、10个横向管理系统（M01～M10）。

## 5. 路由与关卡要点

| Gate | 判定对象 |
|---|---|
| G0 | 项目立项、范围、可行性 |
| G1 | 品牌/产品/证据研究 |
| G2 | 商业策略与信息层级 |
| G3 | 创意概念与品牌表达 |
| G4 | 脚本与导演方案 |
| G5 | 分镜与Animatic |
| G6 | 资产/生产准备与授权 |
| G7a | 草稿镜头方案可行性、正式生产放行 |
| G7b | 正式镜头Take可用性、后期放行 |
| G8 | 对每个交付变体+具体文件Hash独立商业审批 |
| G9 | 仅在启动P11时项目复盘关闭；未启动为G9_NOT_APPLICABLE |

G8批准不等于DELIVERED，更不等于CLIENT_ACCEPTED。模拟作品集项目必须使用SIMULATED_APPROVAL，不得伪造客户签收、平台数据或权利。

## 6. 下一阶段测试与风险边界

建议正式启动`T03-09｜模拟/实际商业广告项目端到端试跑`。最小测试方案：30秒商业广告，两种不同交付变体；一个故意失败的QA场景验证REWORK/HOLD、M02和成本入账；测试P11不启动和已启动但无数据分支。

应优先使用**明确标注为模拟**的产品/品牌及内容，除非已提供真实品牌官方资料、权利与许可；不得从无证据资料杜撰真实产品规格、功效或品牌授权。实际AI生成、官方合规、客户验收和投放分析需有相应的真实输入和工具/权限。
