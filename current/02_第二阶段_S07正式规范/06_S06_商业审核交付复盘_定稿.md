# AI商业广告全流程制作 SOP V1.0｜第二阶段 S06
## P10 质量审核与商业交付 × P11 投放反馈与项目复盘｜逐步骤标准与G8/G9审核

**标准版本：** Standard Draft V0.1（S06首版；待S07综合复审）  
**编制日期：** 2026-11-02  
**上位架构：** 第一阶段 Architecture Baseline V1.0；12阶段、99项候选步骤；10个主Gate（G7分为G7a/G7b）  
**上游依赖：** S00–S05全部首版规范；P9移交`MASTER_CANDIDATE`而非正式获批母版  
**覆盖范围：** P10-01～P10-10（10项）与P11-01～P11-07（7项），合计17项  
**项目边界：** 全类型商业广告，AI为主可混合实拍/CG；个人或小团队；P11为交付后的反馈模块  
**注意：** 本文件定义审查标准、输入输出、责任、Gate、回退和版本关系；不替代当地律师、广告审查机构或广告投放平台审核，也不预设任一地区和平台的实时规范。

> 三项硬边界：**P9成片候选≠P10商业批准；客户审片意见≠客户已验收；投放数据缺失≠广告传播效果为零。**

## 0｜准入、职责与状态

### 0.1 启动约束与权责

| 工作对象 | 准入 | 主要责任 | 准出 |
|---|---|---|---|
| P10成片审核 | P9候选母版、有效G7b记录、P4/5/6/7批准版本、权利链及P0交付矩阵 | 质检/制片统筹；创意、品牌、产品、合规、技术责任人分项签核 | 全部目标版本G8 PASS后进入商业交付 |
| P10商业交付 | G8 PASS、交付文件可读、客户有权签收人、合同及权利范围明确 | 项目/制片负责人与客户授权代表 | 收据或正式验收证据、交付包归档 |
| P11效果复盘 | 投放/发行事件与授权数据，或明确DATA_UNAVAILABLE状态 | 策略/分析人员负责数据；制片负责成本；流程负责人负责改进 | G9 PASS或按条件关闭，改进建议入队列 |

**授权不变量：** 创作者个人可同时担任导演、剪辑、质检、制片，但其内部批准不能自动替代客户、商标权人、音乐权利人或法务机构的授权/批准。作品集项目必须标`MOCK/PORTFOLIO`，不得伪造真实客户审签。

### 0.2 审核决策状态（继承S00）

- `PASS`：证据充分、全部强制项通过，可放行指定版本与渠道；
- `CONDITIONAL`：仅允许**非阻断、可明确关闭日期和负责人的条件项**；不得覆盖法律/授权/产品事实/重大技术错误；
- `REWORK`：必须改正后重审受影响的对象；
- `HOLD`：批准人、证据、政策、许可或必要资料缺失，暂停放行。

重要分级：`BLOCKER`（合法性、权利、产品事实或客户批准等硬阻断）、`MAJOR`（核心信息、关键技术质量或商业传播失败）、`MINOR`（不影响使用的局部问题）、`NOTE`（改善建议）。未经批准不得把BLOCKER/MAJOR降级为“可接受”。

### 0.3 版本状态（防止误称已交付）

`MASTER_CANDIDATE`（P9候选） → `INTERNAL_QA_PASSED`（已完成内部检查） → `CLIENT_REVIEWED`（客户已提出/确认意见，不代表批准） → `G8_APPROVED`（经授权商业批准） → `DELIVERED`（文件交付已证明） → `CLIENT_ACCEPTED`（存在有效客户验收依据）。

所有状态必须有证据，不应跳步。真实合同约定的验收机制可不同，但必须记录依据。无真实客户的模拟项目采用`PORTFOLIO_CLOSE`终态，**不得出现虚构客户签章**；其内部仿真审核状态为`MOCK_G8`，不等于真实商业`G8_APPROVED`。

### 0.4 P10与P11区别

P10回答“**是否具备合法、准确、符合客户要求的可交付版本**”；P11回答“**是否有证据支持广告效果和生产效率的复盘结论**”。P11不以“广告效果优秀”作为关闭项目的硬条件；没有投放数据时，仍可完成成本、执行过程及规范改善复盘，并明确效果不可评估。

## 1｜P10 质量审核与商业交付（10项）

**阶段准入：** P9移交可播放候选及可复现工程，所有引用镜头已获G7b入库资格或有已获准例外；相关品牌/宣称、资产授权、合同交付范围可追踪。  
**阶段准出：** 所有约定版本经G8逐版批准，交付物真实存在、传输有证据、客户验收状态如实登记。  
**顺序提示：** P10-01～06可并行分项审核，P10-07客户审片后P10-08闭环；P10-09技术输出与P10-01～06可交叉复核，但不能用仅母版通过替代所有派生版本通过。

## 2｜P11 投放反馈与项目复盘（7项）

**阶段准入：** 对真实投放版本与数据授权进行核对；没有投放或无法获取数据的项目也必须明确数据可用状态。  
**阶段准出：** 可用证据范围、成本与错误复盘、改善项均已记录，完成G9复盘归档。  

**P11是交付后可选模块：若项目未约定复盘，整体标`P11_NOT_ACTIVATED`且G9=N/A；一旦启动，P11-05～07及复盘记录必须完成。P11启动不代表拥有广告账户数据访问权限，客户授权与平台条款优先。**

## 3｜G8：商业交付放行规则（P10）

### 3.1 必须逐版签核（不得只审核一条16:9母版）

| G8分项 | 证明材料 | 放行失败情形 | 责任人 |
|---|---|---|---|
| 目标与传播 | G2策略、P10-01审核 | 主要信息不完整或误导 | 策略/品牌负责人 |
| 创意与视听 | G3/G4/G5、P10-02/04 | 创意核心丢失，重要音画错误 | 创意/导演/技术负责人 |
| 产品与品牌 | 权威SKU与Logo资料、P10-03 | 型号、包装、宣称或商标错误 | 产品/品牌授权人 |
| AI与画面质量 | G7b + P10-05成片复核 | 产品变形、人物严重漂移、明显穿帮 | AI制作/QA |
| 权利与法律 | M08台账、P10-06适用矩阵 | 未获授权、无法支持的宣称、必须披露事项缺失 | 授权合规负责人 |
| 客户决策 | P10-07/08客户意见及批准证据 | 未经客户最终授权或存在未关闭重大意见 | 客户授权决策人 |
| 平台版本 | P10-09逐版验证记录 | 时长/画幅/编码/安全区/地区语言不符 | 后期技术负责人 |
| 交付准备 | P10-09文件实测、拟交付清单与hash | 交付文件缺失、不可打开、版本混乱 | 项目/制片负责人 |

- `G8=PASS`的对象必须是**具体的`delivery_variant_id + master_candidate_version + file_hash + market + platform`**，不是笼统的“广告已通过”。
- 产品事实/权利/合规问题、重大未关闭缺陷、合同要求的客户批准缺失不得`CONDITIONAL`放行。
- G8通过不等于文件已送达；P10-10要单独取得交付和验收证据。
- 审核期间如发生产品更新、活动日期变更、目标国家增加、音乐使用范围变化，应暂停受影响版本，并重新执行对应审核。

### 3.2 交付版本矩阵——字段规范

`delivery_variant_id | parent_master_id | aspect_ratio | duration | frame_rate | resolution | color_space | audio_layout | codec_container | subtitle_language | region | channel | rights_territory | platform_spec_source | checked_at | technical_qc | brand_qc | legal_qc | G8_status | file_hash`

上述字段部分可能不适用（例如无声广告的音轨参数），应标`N/A+原因`；并非所有市场强制填写同一种固定分辨率、编码和响度标准。渠道要求应以项目实际渠道和核对日期为依据。

### 3.3 素材权利与广告宣称矩阵

每条`claim_id`记录**原文、投放地区/语言、证据文件、证据适用范围、证据有效性、广告出现时间码、审批状态**。每条许可/授权记录**权利主体、作品或素材ID、允许用途、平台、地域、期限、是否可修改/二次制作、是否允许广告商用、授权证据及到期日期**。此外，根据地区与平台要求维护AI合成内容披露、代言与肖像、隐私及受众限制的单独检查项。

**注意**：AI生产日志保留不等于自动获得第三方图片、音乐、商标或人物肖像的使用权。

## 4｜G9：投放反馈与项目复盘关闭（P11）

### 4.1 数据可用性与证据级别

| 数据状态 | 定义 | 允许得出的结论 | 禁止的结论 |
|---|---|---|---|
| `MEASURED` | 真实平台/客户数据，有版本映射、口径与授权 | 在明确观察窗口和渠道下的描述性效果；具备有效实验/对照时可讨论因果 | 不经可比性检验声称素材导致业绩增长 |
| `PARTIAL` | 部分地区/渠道/时间或指标缺失 | 明确限于样本覆盖范围的观察 | 外推到全部用户、全部投放或完整ROI |
| `QUALITATIVE_ONLY` | 仅合法收集的用户意见、内部审片/调研反馈 | 关于感受、理解和问题的定性判断 | 声称测得CTR、ROAS、购买增量等数据 |
| `DATA_UNAVAILABLE` | 未获数据权限、未投放或数据不可用 | 制作过程、成本、质量与流程复盘；明确效果不可评估 | 捏造曝光、转化、利润或归因值 |

### 4.2 KPI与计算口径（仅作字段定义，不预设达标阈值）

| 指标 | 推荐表达 | 注意事项 |
|---|---|---|
| CTR 点击率 | 点击数 / 曝光数 ×100% | 各平台“点击”含义可能不同；报告使用原定义 |
| VTR 视频观看率 | 满足指定观看事件的人次或次数 / 相应曝光或播放基数 | 必须说明“播放”“3秒观看”“完整观看”等事件的定义和分母 |
| CVR 转化率 | 转化次数 / 指定可归因的基数 ×100% | 分母可能为点击、访问或会话，必须明确，不能统称CVR而不写口径 |
| CPM 千次展示成本 | 广告花费 / 曝光次数 ×1000 | 广告费，不等于内容制作费 |
| CPC 单次点击成本 | 广告花费 / 点击数 | 分母为零记不可计算 |
| CPA 单次转化成本 | 广告花费 / 归因转化次数 | 必须明确归因窗口、平台或第三方口径 |
| ROAS 广告支出回报 | 归因收入 / 广告花费 | 不等于ROI，不扣除商品成本及全部其他成本 |
| 素材生产单价 | 内容制作实付成本 / 合格交付成片或镜头数 | 必须说明分母以及多版本共享成本分摊规则 |
| 返工费用率 | 返工增量成本 / 实际总制作成本 ×100% | 返工是成本子集，不重复加到总成本 |

任何分母为0或缺失时标`N/A`，不得填0来冒充结果。跨币种需保存汇率来源/计算时点；跨平台对比要核对归因窗口、事件去重、受众与投放条件。

### 4.3 创意效果归因等级

- **D0：无效果数据。** 只能谈作品质量和内部执行。
- **D1：描述性表现。** 如曝光、点击或播放指标，仅报告观察。
- **D2：相关性/对照观察。** 有可比投放单元，但存在分发、人群和算法偏差，明确限制。
- **D3：可信实验或可审计因果设计。** 才可较谨慎描述广告素材对指标的增量作用；需要相应实验设计证据和有效结果。

**禁止仅凭一条广告的单次表现，宣称某类画面或运镜普遍提升转化率。**

### 4.4 G9关闭检查

- 项目是否真实投放、是否获数据授权、数据覆盖范围及状态明确；
- 能计算的指标有分子分母、观察期、来源和具体变体；不能计算的标缺失；
- 所有生产成本项目有可追溯实际数/缺失说明；与投放消耗明确分开；
- 重大失败、返工及客户意见有根因/责任环节/改进项；
- SOP/Skill改进仅登记建议，批准后方可修订；
- G9批准人、复盘日期、归档位置明确，项目可以在`DATA_UNAVAILABLE`状态下完成非效果复盘。

## 5｜全链数据ID、审查对象与追踪结构

```
project_id
  ├── brief_version / objective_id / audience_id / claim_id
  ├── creative_version / script_version / director_version
  ├── beat_id → shot_id → asset_id
  ├── shot_id → production_task_id → take_id → G7b_selection
  ├── master_candidate_id → delivery_variant_id → G8_approval_id
  ├── delivery_id → receipt_id → client_acceptance_id (若真实客户)
  └── campaign_id / ad_id → source_report_id → metric_definition_id → G9_review_id
```

- 一次交付可能包含多平台、多语言、多时长、多画幅，因此`master_candidate_id`不等于`delivery_variant_id`。
- `delivery_id`指一次交接事务，多个文件可在同一次交付；一个文件也可能有后续修订版。
- `campaign_id/ad_id`是投放系统中的实际标识；模拟练习不得伪造真实投放实体。
- P10/P11都通过`delivery_variant_id`追溯到实际视频文件，避免把上传的旧版广告和最终新版本的数据混用。

## 8｜交付清单、保留策略与安全边界

### 8.1 最小交付包（具体按合同）

1. 已批准的广告成片文件及逐版本元数据、文件校验信息。
2. 交付变体矩阵，明确每种语言、时长、画幅、平台、地区及对应权利。
3. 批准的文字稿/字幕及品牌材料版本，必要时提供字幕侧车文件。

5. 客户明确约定的源工程、素材包或归档说明；**源工程不是默认无偿交付项**。
6. 审片记录、G8批准、签收/验收状态和遗留责任项。

### 8.2 保留与权限

仅授权成员可访问源素材、合同、平台账户或敏感投放数据。项目保留期限依据合同、法律与客户约定，不统一规定“永久保存”；删除/归档应有责任人与可审计记录。用于SKILL训练或公开作品集的客户素材需再次核实许可，不因内部制作获得自动公开权。
