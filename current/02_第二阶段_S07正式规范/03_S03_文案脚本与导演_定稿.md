## 0｜S03架构约束与交付条件

### 0.1 阶段职责和不可越界事项

| 层级 | 必须回答的问题 | 交付对象 | 不得越界的内容 |
|---|---|---|---|
| P3 创意策划 | **为什么**采用这个创意表达品牌？ | 获批创意概念与表现机制 | 不直接把未批准脚本投入制作 |
| P4 文案脚本 | **具体说什么、发生什么、信息何时出现？** | 可按时间理解的内容脚本、文字与信息映射 | 不锁定逐镜头机位、景别、焦距、视频提示词 |
| P5 导演视觉 | **如何以视听语言表达这些内容？** | 导演意图、视觉/声音原则、制作约束 | 不批量生成正式资产、不替代分镜、不修改批准的商业承诺 |
| P6 分镜预演 | **要用哪些镜头，如何连接，能否在时长内实现？** | 分镜表、分镜图、Animatic | 不擅自修改P4传播信息、P5关键风格规范 |
| P7 资产制作 | **用哪些稳定资产实际执行镜头？** | 正式产品/人物/场景等资产及映射 | 不将概念参考直接当作已审核的商品实物 |

P4与P5可以受控交叉修改；**G4在P4和P5均审核通过后统一放行**。P4的内部“已核对”不等于整体G4已通过。

### 0.2 进入S03的强制前置条件

- G0～G3所需的有效批准记录存在，P3创意提案明确版本且能追溯P2主传播信息。
- P0含广告目标、投放渠道、语言/地区、交付时长或时长区间、品牌审批人。
- P1拥有产品事实/证据及宣称台账，未经核实的信息必须明确标记状态。
- P2含主要受众、单一主信息、价值主张、主要行动或品牌反应、效果指标定义。
- P3含已批准创意概念、视觉机制、产品和品牌预期露出、初步制作可行性及风险。
- 可在欠缺非关键参考资料时进入工作，但阻断性缺口不能跨过G4。严禁把猜测的产品性能写成获证实广告语。

### 0.3 S03必须交付的四个包

1. **P4脚本包**：内容节拍表、文案/宣称台账、旁白与对白文本或无语音说明、完整主版脚本、品牌/产品/CTA映射、审查记录。
2. **P5导演包**：导演阐述、视觉风格圣经、美术/摄影/灯光/色彩/空间/人物与产品/声音规则、制作风险与可行性说明。
3. **联合追踪包**：P3批准概念→P4 `beat_id`→P5 `director_rule_id` 的双向对应关系；向P6传递镜头需求而非提前锁定`shot_id`。
4. **G4批准包**：被审文件版本、审核问题、决策、批准责任人、需修改项、影响范围及状态。

### 0.4 角色责任

| 责任项 | 执行人 | 必要审核/确认 |
|---|---|---|
| 传播内容与卖点 | 文案/策略负责人（可兼任） | 策略负责人 + 对产品事实有授权的品牌方 |
| 脚本结构与时长 | 文案/导演 | 创意负责人、项目负责人 |
| 摄影/美术/声音方向 | 导演与相关专业负责人（可兼任） | 导演负责人、品牌视觉审批人（需要时） |
| 合规与版权风险 | 指定合规审核责任人 | 必须取得适当授权/证据，不得自行替客户背书 |
| G4最终批准 | 项目审批人/有权客户代表 | 批准证据可回溯；作品集项目标记模拟审批 |

个人可以兼任制作岗位，但不能假装获得不存在的客户批准或第三方授权。

### 0.5 统一状态与编号

- `DRAFT` → `REVIEW` → `APPROVED_FOR_DIRECTION`（仅P4内部）→ `G4_PASS` → `LOCKED`；无权跳过G4。
- 内容节拍使用 `AD001_B001`；导演规则使用 `AD001_DR001`；文案使用 `AD001_CP001`；事实宣称复用P1 `claim_id`；镜头`shot_id`必须由P6正式生成。
- 改版只新增版本（例`v02`），不覆盖已锁定版本；删除的节拍/文字保留作废记录，修改必须有M02变更单。
- 所有交付物沿用S00通用元数据；`related_shot_ids`在P4/P5通常为空，不应伪造。

## 1｜P4 广告文案与脚本：7项逐步规范

**准入**：G3通过。**准出**：形成P4候选审核包并进入P5，最终在G4联合审核。  
**核心成功定义**：所有商业信息、品牌露出、广告语言和内容节拍可追溯、能进入导演和分镜设计；没有未核实的事实性广告承诺。

### P4-01｜广告内容结构设计

| 规范字段 | 确定要求 |
|---|---|
| 业务目的 | 将已批准创意和主要信息组织为完整广告内容节拍，确定信息出现顺序与时长预算。 |
| 适用性 | **强制**；全部广告类型。 |
| 输入与证据 | P0交付时长与渠道、P2单一主信息/CTA、P3获批创意及品牌露出机制。 |
| 职责与边界 | 文案/创意负责人规划内容段落；只指定节拍级时长，不预设具体分镜数量。 |
| 输出与字段 | 《内容节拍表》：`beat_id`、内容摘要、传播功能、起止时间、主信息、品牌/产品出现状态、衔接关系、时长总和。 |
| 完成判定 | 所有节拍有唯一ID；时间覆盖从0到目标时长且不重叠；主要商业信息和广告结尾有明确承载位置；无无目的重复节拍。 |
| 审批与Gate | 创意负责人内部审核；G4复核其与P3/P2一致性。 |
| 错误与回退 | 缺少主信息→P2；创意结构不可成立→P3；仅时长或排序不合理→本步骤。 |
| 版本与记录 | 保存时间分配变化、节拍新增/合并/删除记录，已废弃ID不可复用。 |

### P4-02｜广告叙事方式设计

| 规范字段 | 确定要求 |
|---|---|
| 业务目的 | 规定广告是叙事、演示、概念隐喻、证言/口播或混合表达，以及观众如何逐步理解。 |
| 适用性 | **强制**；无剧情的产品广告也必须说明其非叙事表达机制。 |
| 输入与证据 | P3创意机制、P4-01节拍、P2受众认知与传播策略。 |
| 职责与边界 | 明确叙事视角、时空关系、信息揭示及情绪曲线；不设计镜头轴线和具体表演动作。 |
| 输出与字段 | 《叙事机制说明》：`narrative_mode`、理解路径、首要注意力点、信息揭示节点、情绪推进、必要因果关系、表达限制。 |
| 完成判定 | 观众无需额外背景知识即可理解关键内容；叙事因果或演示逻辑没有明显缺口；机制与P3创意相符。 |
| 审批与Gate | 创意负责人、导演初步会审；G4联合复核。 |
| 错误与回退 | 概念与策略冲突→P3；叙事跳跃→P4-01/02；视觉表达难以执行→反馈P5。 |
| 版本与记录 | 叙事模式修改必须记录对文案、导演、节拍的影响。 |

### P4-03｜广告文案撰写

| 规范字段 | 确定要求 |
|---|---|
| 业务目的 | 将核心传播信息转换为可上屏、可朗读或可用于广告包装的准确文字。 |
| 适用性 | **强制**；无文案广告需提交`NO_COPY`声明及品牌识别说明。 |
| 输入与证据 | P2信息卡、P1证据台账、P3主题及品牌语言规范、P4-01/02。 |
| 职责与边界 | 文案负责标题、口号、辅助语、卖点、CTA及免责声明；不得自行增加未经批准的功能效果。 |
| 输出与字段 | 《文案台账》：`copy_id`、文字原文、用途、出现节拍、语言、字符限制（渠道有规定时）、`claim_id`、证据状态、版本、品牌审批状态。 |
| 完成判定 | 每个事实性/比较性/量化承诺能关联已核实证据；产品与品牌名称一致；口号、上屏文案及免责声明准确且符合投放市场；无无意的绝对化承诺。 |
| 审批与Gate | 品牌文案审批人 + 事实/合规责任人审查；G4不得批准阻断性宣称。 |
| 错误与回退 | 产品数据错误→P1；卖点方向错误→P2；文字表达错误→本步骤；口号策略不符→P3。 |
| 版本与记录 | 记录每条copy的`APPROVED/TO_VERIFY/REJECTED`状态、文字修改前后值与签批证据。 |

### P4-04｜旁白与对白设计

| 规范字段 | 确定要求 |
|---|---|
| 业务目的 | 规定声道中传达哪些语言信息及相应文本和时长约束。 |
| 适用性 | **条件强制**：出现旁白/对白/口播/语音播报时编制完整台词；无语音时提交`NO_SPOKEN_AUDIO`决定。 |
| 输入与证据 | 文案台账、节拍表、目标地区和语言、P3品牌调性。 |
| 职责与边界 | 指定每条台词发声角色、文本、音色意图、情绪、所属节拍、预计语速和时长；具体表演/混音交P5/P9。 |
| 输出与字段 | 《语音脚本》：`voice_line_id`、`speaker_id`、`beat_id`、原文/本地化版、预计时长、语气/重音、同步需求、授权/配音状态。 |
| 完成判定 | 语音总时长可容纳在所属节拍内；声画不相互否定；目标语言准确；若人声被使用，明确实际配音或合成语音的使用及授权风险。 |
| 审批与Gate | 导演与文案联合审；品牌方确认语音文字。 |
| 错误与回退 | 信息冗余或语速失控→P4-01/03；人物角色不合逻辑→P4-02；配音路线风险→P5-08。 |
| 版本与记录 | 台词逐行编号，语种/区域和发声者变化均有版本记录。 |

### P4-05｜广告脚本编写

| 规范字段 | 确定要求 |
|---|---|
| 业务目的 | 汇合节拍、叙事、文案、配音和品牌信息，形成能交给导演的完整广告脚本。 |
| 适用性 | **强制**；全部广告类型。 |
| 输入与证据 | P4-01～04成果、P3批准创意、P0交付矩阵。 |
| 职责与边界 | 输出“时间段+画面事件+传播任务+声音/文字”的脚本；不提前规定全部镜头编号/机位/镜头数量。 |
| 输出与字段 | 《广告脚本主版》：`script_id`、`master_duration`、`version`、`beat_id`、起止时码、画面事件、商业任务、台词、上屏文字、产品/品牌状态、证据与权利标记、变体约束。 |
| 完成判定 | 时码闭合、全部节拍顺序清晰、台词与画面可共存、主信息不丢失、开场/主体/收尾满足所选广告路线，不存在孤立未批准内容。 |
| 审批与Gate | 创意/文案负责人内部通过，作为P5导演设计基础；最终受G4锁定。 |
| 错误与回退 | 情节/信息顺序问题→P4-01/02；未获批宣称→P4-03/P1；影片风格冲突→与P5联动修订。 |
| 版本与记录 | 主版和各时长/平台改编版必须有父子版本关系，禁止覆盖主版。 |

### P4-06｜产品卖点与品牌信息植入

| 规范字段 | 确定要求 |
|---|---|
| 业务目的 | 核对产品、品牌、主传播信息和CTA在广告时间轴内是否被有效承载。 |
| 适用性 | **强制**；CTA在不适用的品牌认知项目可标记`N/A`并说明原因。 |
| 输入与证据 | P1产品/Logo事实台账、P2核心信息卡、P3品牌露出机制、P4-05脚本。 |
| 职责与边界 | 检查植入合理性、露出位、表达载体与证据关联；不代替P6设计具体产品特写镜头。 |
| 输出与字段 | 《品牌/卖点映射矩阵》：`brand_item_id/claim_id`、`beat_id`、信息类型、视觉/声音载体、必要性、限制、状态。 |
| 完成判定 | 必需品牌信息和主要价值主张存在明确出现位置；事实性卖点经核实；需要CTA的版本设有可识别行动引导；无冲突宣称。 |
| 审批与Gate | 品牌方、策略/合规负责人确认；G4必查。 |
| 错误与回退 | 露出位置缺失→P4-01/05；品牌策略不符→P2/P3；Logo真实性问题→P1/P7。 |
| 版本与记录 | 任何信息植入调整须更新节拍、文案、脚本和映射表的一致性。 |

### P4-07｜广告脚本审核与确认

| 规范字段 | 确定要求 |
|---|---|
| 业务目的 | 形成经内部审查且可交给导演继续深化的P4候选基线。 |
| 适用性 | **强制**；全部广告类型。 |
| 输入与证据 | P4-01～06交付包、G3记录、P0-P2约束及未关闭问题。 |
| 职责与边界 | 逐项复核时长、传播信息、产品事实、文字与语言、适配分支和可制作性；此步骤不单独替代G4。 |
| 输出与字段 | 《P4脚本审查单》：检查项、问题级别、责任人、处理状态、批准候选脚本及关联版本。 |
| 完成判定 | 无BLOCKER；MAJOR问题在G4前均已解决；未关闭的MINOR问题有负责人和处理条件；脚本有明确版本。 |
| 审批与Gate | 文案/策略/导演负责人审查，必要品牌确认；状态可记为`APPROVED_FOR_DIRECTION`，最终G4确认。 |
| 错误与回退 | 按最早的错误步骤返工，记录受到影响的文案、时码、品牌露出和后续导演设计。 |
| 版本与记录 | 保存审查结论、缺陷单及所有批准证据，不重写原批准版本。 |

## 2｜P5 导演分析与视觉开发：9项逐步规范

**准入**：存在P4可用于导演开发的候选脚本及P3已批准创意。**准出**：P4+P5联合提交G4。  
**核心成功定义**：每项视听决策都能解释其商业和观众体验目的，具备一致、可传递、可检查的规则，且不把导演概念错误当作已定稿资产或镜头。

### P5-01｜广告导演思维分析

| 规范字段 | 确定要求 |
|---|---|
| 业务目的 | 将品牌目标、创意概念和脚本转译为导演的观看任务、节奏与视听表达意图。 |
| 适用性 | **强制**；全部广告类型。 |
| 输入与证据 | P2核心信息、P3概念、P4候选脚本、P0平台和时长要求。 |
| 职责与边界 | 分析注意力焦点、观众知晓顺序、情绪/信息变化、品牌记忆及产品呈现目的；不要求每支广告都具备人物戏剧冲突。 |
| 输出与字段 | 《广告导演阐述》：导演意图、受众观看路径、关键观看任务、节拍→视听策略映射、风格禁忌与制作风险。 |
| 完成判定 | 所有关键导演决定能对应具体`beat_id`和商业目的；无与已批准脚本/品牌策略冲突的自行改写。 |
| 审批与Gate | 导演负责人、创意/策略负责人联合确认；G4审核。 |
| 错误与回退 | 观看任务不清→P5本步骤；商业任务矛盾→P2/P4；核心创意不适合→P3。 |
| 版本与记录 | 导演阐述关联P4脚本版本；每次脚本改动应执行影响分析。 |

### P5-02｜广告视觉风格定位

| 规范字段 | 确定要求 |
|---|---|
| 业务目的 | 明确画面整体美学和品牌视觉方向，建立跨镜头的统一性依据。 |
| 适用性 | **强制**；全部广告类型。 |
| 输入与证据 | 品牌VI、P3视觉概念、P4内容、P5-01导演意图。 |
| 职责与边界 | 定义摄影真实感、视觉质感、画面调性、参考和禁用风格；参考图不是可直接商用授权凭证。 |
| 输出与字段 | 《视觉风格定位卡》：风格关键词、正反向参考、品牌关联、视觉红线、不同渠道变化范围。 |
| 完成判定 | 风格能被视觉语言具体描述，不依赖空泛形容词；与品牌VI无冲突；提供至少一组不应出现的风格风险。 |
| 审批与Gate | 导演/美术负责人，品牌视觉负责人（适用时）；G4审核。 |

## 3｜交付物结构与最低字段规范

### 3.1 广告脚本主版（Script Master）

必填文档头：`project_id`、`script_id`、`version`、`parent_version`、`creative_approval_ref`、`strategy_ref`、`target_duration`、`primary_channel`、`languages`、`status`、`owner`、`reviewer`、`claim_register_ref`、`rights_register_ref`。 

脚本正文每一节拍至少包含：

| 字段 | 规范 |
|---|---|
| `beat_id` | 唯一且不可复用；P6未来镜头可引用多个beat |
| `t_in` / `t_out` | 统一以时间区间表示，要求首段从0开始、连续、不重叠；正式帧率锁定后可转时码 |
| `visual_event` | 观众实际可见的事件/主体/产品展示，不填空泛情绪词 |
| `communication_job` | 本段传播任务（吸引注意/介绍产品/证明价值/品牌识别/CTA等） |
| `primary_message` | 本段要传达的商业信息；不等于声画中的全部台词 |
| `copy_refs` / `voice_refs` | 引用已编制的文案及语音条目；无时明确`NONE` |
| `product_brand_presence` | 产品/包装/Logo/品牌名称/CTA出现状态及必要性 |
| `claim_refs` | 涉及产品事实时关联P1证据编号；无则`NONE` |
| `sound_intent` | 声音表达任务；详细Cue由P5-08深化 |
| `dependency_notes` | 需要P5验证的可行性、风险、逻辑限制 |

**时长判定**：节拍相接 `t_out(i)=t_in(i+1)`，节拍总时长等于`target_duration`；长度未最终确定时只允许明确标注试选时长，不得冒充锁定时长。固定帧率后的调整由P6与P9验证完整帧数。

### 3.2 文案、台词和宣称引用表

- 文案：`copy_id｜verbatim_text｜copy_type｜language/locale｜beat_id｜claim_id/NONE｜approval_status｜restriction_notes`
- 台词：`voice_line_id｜verbatim_text｜speaker_id｜beat_id｜estimated_duration｜intonation_goal｜sync_requirement｜voice_rights_status`
- 宣称：只**引用**P1的`claim_id`，不在P4悄悄发明新的、未批准的宣称；需新宣称时发起P1核实并更新P2/P4。
- 品牌：`brand_asset_id｜approved_asset_version｜beat_id｜prominence_requirement｜brand_owner_approval`。

### 3.3 导演阐述与视觉圣经（Director Bible）

| 章节 | 必填内容 | 下游使用阶段 |
|---|---|---|
| 01 导演目的 | 观众注意、信息与情绪任务 | P6 |
| 02 风格定位 | 风格主张/禁忌/参考使用边界 | P6/P7/P8 |
| 03 美术原则 | 场景/服装/道具/材质主次关系 | P7 |
| 04 摄影原则 | 景别/机位/运动/主体阅读顺序的选择准则 | P6 |
| 05 光影色彩 | 产品真实颜色、反射、照明与观感限制 | P7/P8/P9 |
| 06 空间规则 | `space_id`、锚点、主方向与连续性限制 | P6/P7 |
| 07 主体规则 | `subject_id`、产品不可变项、人物视觉/表演基准 | P7/P8 |
| 08 声音原则 | Cue类别/品牌音频意图/静音替代 | P6/P9 |
| 09 生产与风险 | AI/实拍/CG候选路线、重点难点、授权/成本风险 | P6/P7/P8 |
| 10 脚本规则对应 | `beat_id→director_rule_id`、需导演复核项 | P6 |

P5的镜头语言只是**选择规则**，不固定`shot_id`；正式镜头设计、景别机位、镜头持续时间、逐镜运镜和相邻镜头衔接由P6管理。

### 3.4 版本与适配文件

母版脚本必须独立于派生版本。派生版本需记录：`variant_id`、`parent_script_id`、目标时长、渠道/地域/语言/画幅、保留的关键传播任务、必须新增或删减的内容、审核状态。禁止以简单截断替代内容重构；不同画幅可改变镜头设计但不可悄悄改写已批准的产品宣称。

## 4｜广告类型路由的特殊验收

| 路线 | P4必须确保 | P5必须确保 | G4特有风险 |
|---|---|---|---|
| 品牌形象/TVC | 主品牌信息、品牌识别和情绪路径完整 | 风格与品牌识别有辨识度，不只追求电影感 | 品牌完全缺席、华丽但无传播信息 |
| 产品展示/科技产品 | 产品特点/演示台词准确，所有功能性承诺可核实 | 产品结构、材质、比例、可用功能不失真 | AI虚构按钮、接口、功效或外观 |
| 创意概念广告 | 概念机制与产品/品牌存在可解释关联 | 视觉隐喻的观看路径清楚 | 创意与商业信息脱节 |
| 效果转化/信息流 | 用户利益、行动引导和必要声明清楚 | 在目标渠道可读、静音也能理解关键信息 | 强制CTA缺失、夸张保证结果 |
| 叙事/人物广告 | 人物行为服务传播任务，因果完整 | 表演风格与镜头视点可信 | 叙事过长挤占商品/品牌信息 |
| 发布活动/多语种 | 版本时间、活动内容、地区条件正确 | 各语言视觉文字安全区、音画节奏可调 | 日期、价格、适用地区/语言错误 |
| AI+实拍+CG混合 | 脚本中无法执行的实拍效果/技术条件不得被当作已确认 | 产品实物参考、空间、光照和运动可建立跨素材连续原则 | 素材风格无法衔接、授权或质量来源不清 |

特殊规则是叠加而非互斥：一支30秒科技产品转化TVC同时受多个路线约束。

## 5｜既有AI导演体系的模块对接

原则：**引用既有专业能力，不复制整本影视导演教材到广告SOP；商业总控层增加“广告传播任务”约束。** 可定位的已有导演模块包括《单场戏导演创作体系》01～10等；其准确工作文件版本和项目安装状态，在实际集成时以项目Skill清单核验，不能仅凭相同文件名推断已安装。

| 现有导演专业能力 | 本S03接入位置 | 商业广告的新增约束 | 交P6/P7的主要接口 |
|---|---|---|---|
| 剧情功能 / 观众体验 | P5-01 | 将“剧情功能”拓展为“传播任务/观众信息任务”；不强迫非叙事广告拥有戏剧冲突 | `beat_id→viewing_goal` |
| 人物分析/表演 | P5-01、P5-07（条件） | 模特表演应服务品牌身份、消费者体验和使用场景 | `subject_id→performance_rule` |
| 场面调度 | P5-04、P5-06（条件） | 产品与人物在画面内的视觉主次必须明确 | 空间规则与主体移动约束 |
| 空间与动作连续性 | P5-06、P5-07 | 产品位置、包装、开合动作、前后状态保持一致 | `space_id`、`subject_id`、状态锚点 |
| 镜头语言 | P5-04 | 选择镜头先问“需要传达什么”，不是追求运镜数量 | 摄影选择准则，逐镜落地交P6 |
| 视觉美术 | P5-02/03/05/07 | 商品颜色、比例、Logo与品牌VI成为刚性约束 | 视觉圣经、产品不可变项 |
| 声音设计 | P5-08 | 增加品牌音频识别、台词可懂度、静音播放替代 | Cue意图，具体混音交P9 |
| 视频提示词与生成Skill | **不在P5直接执行** | P8调用时需读取P4/P5已锁定基线 | P6镜头与P7资产共同传入P8 |

**不默认继承的影视假设**：每条广告都需要人物、戏剧冲突、完整三幕式结构、固定比例长镜头、固定16:9画幅。应以广告类型与P0渠道要求决定。

## 6｜G4联合审核、阻断规则及回退

### 6.1 G4审查包与签批顺序

1. **P4商业内容审核**：时长/节拍完整；文案与语音核对；产品/宣称/品牌信息与批准证据一致。
2. **P5导演表达审核**：导演观看任务、摄影/美术/声音规则一致且可行；未覆盖或损害产品的真实属性。
3. **跨包一致性核对**：每一个关键`beat_id`有对应导演任务；所有刚性品牌与产品要求在导演规范中被保留。
4. **技术与成本前评估**：高风险镜头类型明确交给P6/P7验证；无法制作的核心机制必须先处理或发起上游变更。
5. **有权人批准**：结果只能为PASS/CONDITIONAL/REWORK/HOLD，必要时附批准证据与后续条件。

### 6.2 硬性阻断（BLOCKER）

- 存在未经证实但被写为事实的核心产品功效、规格、比较性或量化宣称。
- 关键品牌/产品名称或官方包装表达错误，且不能在当前脚本或导演规范下纠正。
- 未解决的必要版权、肖像、商标或声音授权问题，且项目方案依赖该素材。
- 主传播任务与获批准P2/P3相矛盾，无法完成本次广告目标。
- 客户要求的目标媒体或适用地区存在已明确的禁止性内容或必要披露缺口。
- P4或P5缺少有效批准来源，或者核心文件不具版本可追溯性。

### 6.3 重大问题（MAJOR）

- 内容节拍总时长与目标时长不一致或无合理适配方案。
- 品牌出现机制太弱，目标受众难以识别广告主体。
- 剪辑/导演预设中的信息顺序难以理解，关键因果丢失。
- 摄影/美术/声音规则互相冲突，P6难以据此设计镜头。
- 已知AI生成难点依赖高成本反复抽卡但无可行替代路线。
- 多语言/多画幅版本缺少基本保留信息的规定。

### 6.4 G4验收记录最小字段

`gate_id=G4｜project_id｜p4_script_version｜p5_director_version｜creative_version｜claim_register_version｜rights_review_ref｜reviewers｜decision｜blocking_findings｜major_findings｜approved_conditions｜owner｜approval_evidence｜date`。

PASS后P4+P5同步进入`LOCKED`。CONDITIONAL只适用于非阻断的、具负责人和截止条件的低风险项目；涉及事实与权利的硬性问题不能附条件放行。 

### 6.5 回退决策表

| 当前发现 | 根因优先归属 | 可能影响 | 应重审 |
|---|---|---|---|
| 核心宣称无依据 | P1 → P2 → P4 | 文案、节拍、品牌视觉、下游镜头 | G1/G2/G4及受影响Gate |
| 商业主信息错误 | P2 | P3、P4、P5及下游 | G2/G3/G4 |
| 创意机制不成立 | P3 | P4/P5、后续分镜及资产 | G3/G4 |
| 台词太长或内容重复 | P4-01/03/04 | 内容时码、旁白、导演声音设计 | G4（如已锁定需M02） |
| 导演风格违背品牌 | P5-02/03 | 视觉圣经、P6/7资产 | G4及受影响Gate |
| 产品包装/比例呈现错误 | P1/P5-07/P7（按根因） | 视觉规则、正式资产、视频镜头 | 相关上游Gate及G4/G6/G7 |
| 某一个镜头机位不合理 | P6 | 该镜头与邻接镜头 | G5及关联下游，不自动推翻G4 |
| AI视频执行畸变 | P8 | 该镜头及可能需要的资产 | G7a/G7b；非上游规则错误不回P4/P5 |
| 后期配音或剪辑问题 | P9 | 成片版本 | G8；如脚本根因才回P4 |
