# AI商业广告全流程制作 SOP V1.0｜第一阶段综合审查与架构定稿
**版本：** Architecture Baseline V1.0  ｜ **定稿日期：** 2026-11-02  ｜ **状态：** 第一阶段架构已冻结；后续变更须走M02
> 本文冻结的是生产架构而非所有执行细则。99项为V1.0候选工作步骤；第二阶段将逐项确定适用条件、强制性及操作接口。

## 1. 用户确认的范围与设计原则
- 广告范围：品牌形象、产品展示、创意概念、商业TVC、科技产品、电商信息流、社交媒体、活动/发布广告。
- 制作方式：AI优先，允许实拍/CG/传统后期混合；不假定所有镜头必须AI生成。
- 组织方式：个人创作者和小团队兼容；一个人可兼多岗，但审批责任不可隐去。
- 边界：从Brief接收到客户交付；P11投放反馈为交付后的独立可选分支。没有投放数据时标为N/A。
- 商业优先：有效传播、品牌准确、产品真实、证据可追溯、版权与法遵是硬约束。

## 2. 综合审查与纠偏结论
| 审查主题 | 发现 | 修订决策 |
|---|---|---|
| 类型重叠 | TVC是渠道/交付形态，不是和产品广告互斥的创意类型 | 采用“传播目标×创意表现×投放渠道×制作方式”的多轴分类 |
| 证据链缺口 | 产品功能、数据、功效可能先被创作再找证据 | P1建事实证据库，P2标记宣称风险，P4逐条对应广告语，P10最终复核 |
| P5/P6/P7边界 | 视觉概念、临时预演资产和正式资产职责混杂 | P5定义规则，P6以概念参考预演，P7生产受控正式资产 |
| P6与P7依赖 | 分镜可能需要正式产品素材才能验证 | 采用“概念代理资产→Animatic→正式资产→必要时局部回改分镜”双向受控迭代 |
| 质量Gate不足 | P8草稿转高清的成本门槛不明确 | 保留主G7并细化G7a草稿放行、G7b正式素材放行 |
| 混合制作缺口 | AI+实拍+CG未统一素材识别和镜头对接 | 统一镜头ID/版本/画幅/帧率/色彩/音轨/权限/来源字段 |
| 后置合规风险 | 广告宣称/肖像/音乐授权到P10才检查代价极高 | M08贯穿P0-P10；高风险宣称在脚本冻结前处理 |
| 客户意见与返工 | 缺少变更影响范围、签批与返工归属 | M02变更单、影响矩阵、重新审核受影响Gate |
| 数据复盘边界 | 拿不到投放数据时易出现臆测 | P11标记实测/仅内部定性/无数据，禁止伪造效果 |

**审查结论：**保留12阶段、99候选步骤、10个主审查节点；把标准化接口、证据链、两级G7、合法合规前置作为强制跨阶段措施。

## 3. 多维项目类型与路由
- 传播目标轴：品牌认知 / 产品教育 / 销售转化 / 活动发布（可设主目标+辅助目标）。
- 创意表达轴：概念隐喻 / 叙事 / 产品演示 / 人物见证 / 动态视觉。
- 分发渠道轴：电视或OTT/CTV / 在线视频 / 社交媒体信息流 / 电商详情 / 线下屏幕。
- 生产方式轴：AI主导 / AI+实拍 / AI+CG / 多方式混合。

| 主路线 | 重点强化阶段 | 特别验收项目 |
|---|---|---|
| 品牌形象 | P2品牌心智、P3创意、P5视听美学 | 品牌辨识、情绪与记忆点 |
| 产品展示 | P1事实、P4产品话术、P7产品资产 | 实物/包装一致性、信息可验证 |
| 创意概念 | P3核心概念、P6视觉逻辑 | 创意可理解、与品牌相关 |
| 转化信息流 | P2行动指标、P4利益表达、P6前段信息节奏 | CTA可见、卖点准确、平台适配 |
| 科技/发布 | P1规格证据、P7产品结构、P9功能动效 | 技术表达不夸大、不伪造真实功能 |
| TVC/CTV | P0渠道规格、P9音画、P10播放验收 | 渠道规定的格式、播出规范与权利 |

*说明：上述路线可叠加，不能把同一项目强制归入唯一广告类型。*

## 5. 审核Gate与冻结点
| 节点 | 位置 | 审核决定 | 必须满足的条件 |
|---|---|---|---|
| G0 | P0后 | 立项放行 | 目标/范围/交付/预算风险/决策人明确 |
| G1 | P1后 | 研究放行 | 品牌识别源、产品事实、待证实宣称和竞品信息可追溯 |
| G2 | P2后 | 策略放行 | 目标受众、主信息、传播目标、CTA及KPI口径明确 |
| G3 | P3后 | 创意放行 | 创意与策略一致、品牌可识别、初步可实现 |
| G4 | P4+P5后 | 脚本/导演放行 | 脚本及文案批准、风格方向批准、关键合规风险处置 |
| G5 | P6后 | 预演放行 | Animatic时长/信息节奏可用、镜头方案锁定 |
| G6 | P7后 | 资产放行 | 产品主资产、镜头资产匹配、技术路线、授权审查通过 |
| G7a | P8草稿后 | 高清放行 | 草稿动作/构图/主信息/连续性/成本风险可接受 |
| G7b | P8正式素材后 | 后期素材放行 | 镜头无阻断性缺陷、技术质量合格、来源可追踪 |
| G8 | P9+P10后 | 商业交付放行 | 品牌、广告宣称、视听、授权、平台及客户审批通过 |
| G9 | P11后 | 复盘关闭 | 实测/无数据状态明确、结论可追溯、改进项有责任人 |

**Gate状态：**PASS（放行）、CONDITIONAL（限期条件放行，不适用于合规硬性风险）、REWORK（返工）、HOLD（暂停/待资料）。
**硬性风险不得条件放行：**缺乏必要权利授权、产品事实失实、未经证实的高风险功效宣称、平台/地区明确禁止内容等。

## 7. 通用工作流状态与最小可追溯链
所有关键信息必须具备：项目ID → Brief版本 → 核心信息/宣称编号 → 创意版本 → 脚本版本 → 分镜ID → 资产ID → 素材ID → 成片版本 → Gate批准 → 发布渠道与反馈。
工作流状态：DRAFT → REVIEW → APPROVED → LOCKED；返工时发起 CHANGE REQUEST，不得直接覆盖锁定版本。
AI与实拍素材同用镜头ID，例如 `AD001_SH012`。修改版使用 `v02`，保留原因、影响范围、审核人和审批日期。

## 8. 返工分类、回退目标及传播
| 问题类型 | 默认回退 | 向下游传播范围 |
|---|---|---|
| 需求错误 | P0 | 所有受影响的阶段 |
| 事实/产品错误 | P1 | P2-P10受影响项 |
| 广告策略错误 | P2 | P3-P10受影响项 |
| 创意错误 | P3 | P4-P10受影响项 |
| 文案/脚本错误 | P4 | P5-P10受影响项 |
| 导演语言错误 | P5 | P6-P10受影响镜头 |
| 分镜连续性错误 | P6 | P7-P10受影响镜头 |
| 资产错误 | P7 | P8-P10受影响镜头 |
| 生成执行错误 | P8 | P9-P10受影响素材 |
| 后期错误 | P9 | P10受影响版本 |
| 审核合规错误 | 最早产生错误的阶段 | 所有使用该信息/素材的版本 |
返工必须执行：记录缺陷 → 确定根因 → 识别最早错误阶段 → 限定受影响镜头/资产/文案 → 更新版本 → 重新运行相关Gate。

## 10. 架构冻结与第二阶段进入条件
**冻结：**12阶段名称与职责、99候选编号、10主Gate+G7a/G7b、M01-M10、多轴路由、版本与回退原则。
**第二阶段可调整：**步骤强制级别、条件分支、交付物字段、评分与验收方法；若涉及阶段调整必须走M02变更。
