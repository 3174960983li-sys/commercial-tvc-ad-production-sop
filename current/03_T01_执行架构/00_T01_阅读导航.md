# T01 文件说明与使用顺序

**版本：**V1.0（第三阶段首个工作包）  
**冻结上游：**S07第二阶段基线（2026-11-02）  
**范围：**T01执行架构、路由、审查，不代表真实广告已制作。

## 阅读顺序

1. `01_T01_执行总纲.md`：三级总控、阶段放行、角色、项目收尾。
2. `02_T01_99步骤任务路由矩阵.md`：99步骤建议依赖和并行路由。
3. `03_T01_Gate与异常回退路由.md`：审核决策、阻断、最小返工。
4. `04_T01_静态验收与T02交接.md`：结构与边界验证、下游接口。
5. `05_T01_99步骤路由数据.json`：供后续工具化参考的结构化草案；**非可执行自动化程序**。

## 本工作包核验

- 解析冻结架构：12阶段、99步骤。
- 所有99步骤在路由矩阵中均有一条记录。
- 所有明确引用的步骤依赖指向现有步骤。
- 正向依赖图拓扑无环（返工循环独立走M02版本变更）。
- 正式Gate、媒体QA、交付和客户验收保持不同对象与状态。
- 未将当前SOP自动误当作视频平台或客户批准工具。
