# T01｜执行架构静态验收与T02交接规范 V1.0

> 本文件是T01设计级自检，不是已执行的真实客户广告测试。检查规则适用性、阻断路径、依赖和审批边界；不得把静态场景的预期结果写成平台实测。

## 1｜检查规则及通过定义

| 编号 | 检验项目 | T01设计应满足 |
|---|---|---|
| T01-Q01 | 架构同一性 | 12阶段、99步骤、10主Gate，G7包含G7a/G7b，不更改第二阶段编号 |
| T01-Q02 | 任务唯一性 | step_id是规范，step_instance_id是项目执行，attempt是一次生成行为 |
| T01-Q03 | 依赖可判定性 | 每项具备可追踪输入、硬依赖和所在阶段的入口Gate |
| T01-Q04 | 拓扑与返工 | 正向依赖无环；返工通过新版本+M02而不是原DAG回边 |
| T01-Q05 | 并行安全 | P4/P5并行仍G4联审；镜头并行不偷越G7a/b |
| T01-Q06 | 混合生产 | 不把LIVE/CG镜头强制为AI草稿；等效验证留证 |
| T01-Q07 | 适用性 | N/A有理由且不能越过事实、权利和客户审批 |
| T01-Q08 | 版本与hash | 最终每个交付版按真实文件hash审核G8 |
| T01-Q09 | 成本账 | 实际/估算/已承诺分离，返工成本是原总账子集 |
| T01-Q10 | 人工决策边界 | AI不能自动以客户名义签批，模拟项目与商业项目分离 |
| T01-Q11 | 数据诚实性 | P11未启用记N/A，无真实数据不制造ROAS等效果 |
| T01-Q12 | T02就绪 | 各步操作教程可从本矩阵获取明确起点与可审查成果 |

## 2｜静态路由样例（预期，不代表真实试跑）

| 编号 | 输入场景 | 应采用的执行决策 | 关键不变量 |
|---|---|---|---|
| C01 | 品牌提供了产品但功效证明待核 | P1事实设TO_VERIFY，阻断相应宣称进入正式脚本/放行 | 未证实宣称不以CONDITIONAL越过 |
| C02 | P4有脚本初稿，P5有视觉概念 | 两者可迭代，G4不能PASS直到两份正式联合审核 | 草稿不是锁定版本 |
| C03 | P6只使用代理分镜图 | 可以G5预演评估，正式素材使用仍走P7/P8及权利审查 | 代理≠商用素材 |
| C04 | 单镜草稿动作失败 | 该镜头P8-06返工，不自动冻结其他已合格镜头 | 局部返工 |
| C05 | 实拍镜头技术测试已可观察验证 | 记录等效验证后允许申请G7a，未生成AI视频仍可合规 | 不伪造AI任务 |
| C06 | 生成失败但已扣费，文件损坏 | attempt_id+cost_entry_id保留，无有效take_id | 费用不漏不重 |
| C07 | 12镜中10镜已过G7b | 已合格镜头可受控后期，整片不能宣称最终镜头集合齐全 | 全片范围不可偷换 |
| C08 | 同一take用于横竖屏，裁切不同 | 新建variant_segment映射，各交付版单独G8 | shot复用但版号不同 |
| C09 | 客户审片通过，但文件未发送 | G8 PASS可批准交付，不能标DELIVERED/CLIENT_ACCEPTED | 审核≠交付≠验收 |
| C10 | 客户修改产品SKU | M02回P1证据与P7产品母版，并影响镜头和交付版 | 根因和影响范围可追踪 |
| C11 | 作品集模拟某知名品牌 | 标PORTFOLIO与模拟批准，不声称品牌授权或实际合作 | 客户签批不可伪造 |
| C12 | 没有真实投放数据 | P11如果启用，数据标DATA_UNAVAILABLE，仅复盘制作 | 无法计算真实转化 |
| C13 | 平台临时新增语言或字幅要求 | 更新对应变体、审核内容和权利，重导出后重查G8 | hash/市场/平台一一绑定 |
| C14 | 项目短剧Skill指定单镜至少2秒 | 广告不自动继承；由Brief和广告镜头需求决定 | 作用域优先级 |
